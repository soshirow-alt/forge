## 構造変更（2026-06 確定 — Cursor 必読）

### 作品管理（旧 → 新）

| 旧 | 新 |
|----|-----|
| 作品ホーム | **22 作品情報** |
| プレイヤーの声 | **23 プレイヤーの声** |
| 開発ログ管理 | **24 開発ログ公開**（リリース統合） |
| リリース管理 | ↑ 統合 |
| 作品設定 | **25 作品設定** |

**Forge ルール**: **開発ログ公開 ≒ 新 ver 公開**

### Studio 階層（旧 → 新）

```
旧: 作品一覧 / プレイヤーの声 / 開発ログ …（同列）
新:
  20 作品一覧
    ↓ 作品選択
  22 作品情報
  23 プレイヤーの声
  24 開発ログ公開
  25 作品設定
  21 分析ダッシュボード（全作品横断・同列ではない）
```

**廃止**: 旧 **20 Studio ホーム**（モック v1 改善ループ版は参考のみ）

### Studio Sidebar 正本（2026-06-16 オーナー確定）

**階層型** — 同列 nav 不採用（GitHub: Repository → Issues / PR / Settings 型）

| Level | 項目 | 画面 |
|-------|------|------|
| **1** Studio 共通 | 作品一覧 / 分析ダッシュボード | 20 / 21 |
| **2** 作品選択後 | 作品情報 / プレイヤーの声 / 開発ログ公開 / 作品設定 | 22 / 23 / 24 / 25 |

詳細: `docs/forge-ui-product-decisions.md` §17–§19

### 21 と 22 の責務（2026-06-16 確定）

| | 22 作品情報 | 21 分析ダッシュボード |
|--|-------------|----------------------|
| 役割 | **作品運営** | **全作品経営** |
| 単位 | 単一作品 | 開発者全体 |
| 例 | Devlog 最新 / 声サマリー / 次にやること / QA | 作品別推移 / 声の推移 / 全体傾向 |
| **禁止** | — | **22 と同じ KPI を重複表示しない** |

### 横断確定事項

| 項目 | 内容 |
|------|------|
| 応援 | **作品単位廃止** → **開発者フォロー** |
| ランキング名称 | **月間影響度ランキング**（見届け人ランキングではない） |
| 共感 | **自由記述 FB のみ** |
| 開発者評価 | **「開発に役立った」** — 非公開 |
| 新規開発者 | **🌱** — 検索可能 |
| 完成品 | **🏆 完成品** のみ。開発中ワッペンなし |
| FB 送信 | **開発者質問 → 自由記述** の順。匿名なし。DM なし |
| 17 設定 | **プレイヤー個人設定**（Studio 設定は 25 等と分離） |
