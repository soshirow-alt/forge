# GPT判断用メモ — 運用ルール

Cursor が **Run 確認前に停止** したとき、オーナーはスクリーンショットではなく **このメモ全文** を ChatGPT に貼る。

---

## 停止対象（必ずメモを出す）

- git **push**（特に `main`）
- **main への反映**（merge / 直接 push）
- **Supabase migration** / **DB 変更** / **削除処理**
- **本番環境変更**（Vercel `--prod` デプロイ、env 変更）
- **課金が発生しうる操作**

---

## フォーマット（Cursor が埋める）

```
====================
GPT判断用メモ
====================

■ 何をしようとしているか

■ なぜ止まったか

■ Runすると何が起きるか

■ Runしないと何が起きるか

■ リスク

■ Cursor推奨

■ 推奨理由

■ オーナーに判断してほしいこと

結論：[A] Run推奨 / [B] 事前確認推奨 / [C] 中止推奨
```

---

## 結論ラベルの意味

| 結論 | 意味 |
|---|---|
| **[A] Run推奨** | リスク低。止まったのは自動安全装置。Run してよい |
| **[B] 事前確認推奨** | オーナーが Dashboard / Vercel で目視確認してから Run |
| **[C] 中止推奨** | 前提不足・データ消失リスク。別手順が必要 |

---

## Cursor の義務

1. Run がブロックされたら、**上記フォーマットを必ず出力**
2. `docs/chatgpt-summary.md` にも同内容の要約を追記してよい
3. オーナーが [A] / Run 承認するまで、該当操作を再試行しない（別経路は要指示）

---

## ChatGPT 側の使い方

1. 「GPT判断用メモ」ブロックだけを貼る
2. 「結論 [B] だけど Run していい？」などオーナー判断を支援してもらう
3. 決定後、Cursor に「Dashboard で 002 実行済み。続けて」と指示
