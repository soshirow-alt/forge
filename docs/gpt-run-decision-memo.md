# GPT判断用メモ — 運用ルール

Cursor が **Run 確認前に停止** したとき、オーナーは **このメモ全文** を ChatGPT に貼る（スクショの代わりに推奨。スクショが貼られた場合も Run 判断依頼として同形式でレビュー）。

詳細トリガー運用: `docs/forge-triage-operations.md`

---

## 停止対象（必ずメモを出す）

**正本**: `docs/forge-triage-operations.md` §10.2（2026-06-16 以降）

以下 **のみ** 停止（旧「push / migration 一律停止」は廃止）:

- **課金が発生しうる操作**
- **新規 API 契約**
- **本番公開**（ユーザー向け GO）
- **PLAYER_VISIBLE=true**
- **DB 破壊変更**
- **既存データ移行**（バックフィル・一括 UPDATE）
- **Forge 原典変更**
- **ロードマップ優先順位変更**
- **不可逆な作業**

main への commit / push、migration **作成**、build、staging 確認、main 反映準備は **停止不要**（一気通貫可）。

---

## フォーマット（Cursor が埋める）

```
====================
GPT判断用メモ
====================

■ 何をしようとしているか

■ なぜ止まったか

■ Runすると何が起きるか

■ Runしないと何が起きるか

■ リスク
（技術リスクに加え、Forge価値 / ユーザー影響 / 復旧難易度）

■ Cursor推奨

■ 推奨理由

■ オーナーに判断してほしいこと

結論：[A] Run推奨 / [B] 事前確認推奨 / [C] 追加確認推奨 / [D] Run禁止
```

---

## 結論ラベルの意味

| 結論 | 意味 |
|---|---|
| **[A] Run推奨** | リスク低。止まったのは自動安全装置。Run してよい |
| **[B] 事前確認推奨** | オーナーが Dashboard / Vercel で目視確認してから Run |
| **[C] 追加確認推奨** | 情報不足・前提未確認。追加質問または確認後に再判断 |
| **[D] Run禁止** | データ消失・原典逸脱・復旧困難など。別手順が必要 |

※ 旧ラベル「[C] 中止推奨」は **[D] Run禁止** または **[C] 追加確認推奨** に読み替える。

---

## ChatGPT 側（Run 判断依頼時）

1. メモまたは Run/Deploy/Migration **スクショ**を Run 判断依頼として扱う
2. 判定は **Forge 原典 → ユーザー価値 → 開発者価値 → MVP → 技術** の順で考える
3. 結論を [A]/[B]/[C]/[D] で明示
4. Cursor 向け指示が必要なら、オーナーが GO した後 **`CURSOR` キーワード運用**（`docs/forge-triage-operations.md` §2）に従い **完成版 1 本**で出力

---

## Cursor の義務

1. Run がブロックされたら、**上記フォーマットを必ず出力**
2. `docs/chatgpt-summary.md` にも同内容の要約を追記してよい
3. オーナーが [A] または Run 承認するまで、該当操作を再試行しない（別経路は要指示）

---

## オーナー側の使い方

1. Cursor 返答の「GPT判断用メモ」または `text` ブロックを ChatGPT に貼る
2. 「結論 [B] だけど Run していい？」など判断を支援してもらう
3. 決定後、Cursor に完成版 1 本で指示（または `CURSOR` キーワードで ChatGPT に生成させる）
