# Forge 画面設計正本

**版**: 2026-06-15（S-22 方針変更 — Player P-06 ベース・正式版タブ廃止）  
**ステータス**: **Forge 画面・機能設計の唯一の正本**（Studio 節は **ドラフト**）  
**用途**: v0 制作 / Cursor 実装 / ChatGPT 仕様共有 / 画面追加・削除・変更時の更新先

**関連ドキュメント**（役割分担）:

| ドキュメント | 役割 |
|--------------|------|
| **本ファイル** | 画面が**なぜ存在するか**・コアループとの関係・遷移の意図 |
| `docs/forge-principles.md` | プロダクト憲法（価値・ルール・作らないもの） |
| `docs/forge-roadmap-2026-06-canonical.md` | 工程フェーズ（Phase0–8） |
| `docs/forge-screen-inventory.md` | 旧 IA 正本（番号・モック対照の参考） |
| `docs/ui-mocks/` | レイアウト・ビジュアル（本ファイル承認後に v0 化） |

**運用ルール**:

- 画面の追加・削除・変更が発生したら **必ず本ファイルを先に更新** する
- v0 制作は本ファイルを入力として行う（overlay・座標合わせは行わない）
- Cursor 実装は本ファイル + 承認済み v0 を正とする
- UX 未確定の画面は **未確定事項** に追記し、実装 GO 前に解消する

## Forge コアループ（判断基準）

### プレイヤー

```
発見 → プレイ → 声を届ける → 変化を見る → 再プレイ
```

### 開発者

```
投稿 → 声を受け取る → 改善する → 開発ログ公開 → 再プレイ獲得
```

各画面定義の **Forgeコアループとの関係** は、上記のどの段階を担うかを示す。  
複数段階に関わる画面は **主担当** を1つ書き、副次は備考に書く。

## ID 体系

| 接頭辞 | 意味 | 例 |
|--------|------|-----|
| **C-** | 共通 UI（Shell / Modal / Drawer 等） | C-03 Player Shell |
| **P-** | ページまたは画面単位 | P-04 ホーム |
| **P-16-T** | マイページ内タブ（種別 Tab） | P-16-T01 見届け中 |
| **S-** | Studio ページ（Player P-26/P-27 との衝突回避） | S-20 Studio ホーム |
| **S-22-T** | Studio プロジェクト詳細内タブ | S-22-T02 声を見る |
| **P-05-2** | 派生画面（開発者検索） | 旧 IA 05-2 と対照 |

**旧番号対照**（`forge-screen-inventory.md`）は各画面の **備考** に記載。

## 記載項目の読み方

各定義は以下の項目を持つ。

| 項目 | 説明 |
|------|------|
| ID | 本書内の一意識別子 |
| 画面名 | 日本語の呼称 |
| 種別 | Page / Modal / Drawer / Toast / State / Tab / Shell |
| 対象ユーザー | プレイヤー / 開発者 / 共通 / 未ログイン 等 |
| 目的 | **なぜこの画面が存在するか**（1〜3文） |
| 主要行動 | ユーザーがここで行うこと |
| 主な流入元 | どこから来るか（ID または導線） |
| 主な遷移先 | どこへ去るか（ID または導線） |
| Forgeコアループとの関係 | プレイヤー or 開発者ループの段階 |
| 備考 | 未確定・旧番号・実装 URL・原典上の制約 |
