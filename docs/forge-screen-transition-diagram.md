## 主要シナリオ（図下部）

### プレイヤー — 作品を探す

```
04 ホーム ──→ 05 作品検索 ──→ 06 ゲーム詳細
（04 から 05 / 05-2 への検索導線も可）
```

### プレイヤー — 開発者を探す

```
04 ──→ 05-2 開発者検索 ──→ 07 開発者プロフィール ──→ 06（代表作品へ）
```

### プレイヤー — 声を届ける

```
06 ゲーム詳細 ──→ 08 フィードバック送信
  ① 開発者質問（最大5）
  ② 自由記述（公開）
```

### プレイヤー — 変化を見る → 再プレイ

```
06 / 07 / 16 / 10 ──→ 06（Devlog・更新・通知経由で戻る）
```

### 開発者 — 改善ループ

```
20 Studio 作品一覧
  ↓ 作品選択
22 作品情報
  ├→ 23 プレイヤーの声（改善材料）
  ├→ 24 開発ログ公開（変化を伝える ≒ 新 ver）
  └→ 25 作品設定
24 公開 ──→ 16 通知 ──→ 06 ゲーム詳細（プレイヤー側）
22 ──緑破線──→ 06（プレイヤー視点確認）
21 分析 ──緑破線──→ 全作品横断参照
```

### エントリ

```
01 ランディング ──→ 02 ログイン / 03 新規登録 ──→ 04 ホーム
```

### マイページハブ

```
09 プロフィール ──紫破線──→ 10 / 11 / 12 / 13 / 14 / 15 / 16 / 17 / 18
（サイドバー IA — 09 がハブ）
```

## 重要ルールまとめ（図下部 — inventory と同一）

| 項目 | 内容 |
|------|------|
| 応援対象 | **開発者**（作品ではない）→ 15 フォロー中の開発者 |
| 共感 | **自由記述 FB のみ** |
| 通信 | 匿名なし / DM なし |
| 新規開発者 | **🌱 新規開発者** — プロフィール表示・検索 FF |
| 完成品 | **🏆 完成品** のみ / 開発中ワッペンなし |
| ランキング | **月間影響度** — 件数のみ禁止。要素: 開発に役立った / 共感 / 新規開発者貢献 / 継続見届け |
| FB 順序 | **質問 → 自由記述**（必須） |
| Studio 分析 | **全作品横断**（作品単位ダッシュボードではない） |
| Devlog | **開発ログ公開 ≒ 新 ver 公開** |
| 11 FB 履歴 | 返信文化なし |
| 12 プレイ履歴 | 進捗率・達成率なし |
