# 法務文書変更サマリ（Owner向け・日本語）

対象: 現行 `/terms`・`/privacy` → `docs/legal/2026-08-*-draft.md`

## 大きく変わる点

1. **ゲストFBを「できる」前提から「Productionでは無効」へ**
2. **「初声」等の旧用語をフィードバック表記へ**
3. **5カテゴリ（ゲーム／音楽・音声／アセット／開発ツール／サービス）を前提にした権利・禁止・免責**
4. **バイナリホスティングではない／外部公開リンク中心**を明記
5. **更新を追う（ウォッチ）通知**を文書化（アプリ内が正。更新メールは現状なし／将来は設定必須）
6. **Feedback reciprocity**を「返礼義務ではない再発見導線」として明確化
7. **処理者を推測ではなく実装事実で列挙**（Supabase / Vercel / Resend / OpenAI / X）
8. **アクセス解析の断定を弱め**、未導入なら書かない方針
9. **運営者の法的身元**は Owner 記入欄（現行「Forge 運営」だけでは不足の可能性）
10. **dev-tool / service**向けにマルウェア・認証情報窃取等を禁止側で強化

## あまり変えない点

- 使用関係 ≠ ライセンス／報酬契約
- メッセージは当事者責任、運営は契約当事者にならない
- FBの公開表示範囲の基本思想
- 準拠法・日本法
