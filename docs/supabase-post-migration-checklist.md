# migration 適用後 — 本番動作確認チェックリスト

**本番 URL**: https://forge-flame-gamma.vercel.app  
**前提**: migration 002 + 003 を Dashboard で適用済み

2 アカウントあると watch → 通知の確認が楽です（A = 視聴者、B = 開発者/オーナー）。1 アカウントでも devlog 投稿・表示は確認できます。

---

## 0. ログイン

| | 内容 |
|---|---|
| **操作** | `/login` → メール・パスワードでログイン（または新規登録） |
| **成功** | トップに戻り、ヘッダーにユーザー名・「通知」「ダッシュボード」「ログアウト」 |
| **失敗** | 赤いエラー（例：メール未確認、パスワード不一致）。画面上部に「Supabaseの環境変数が設定されていません」→ Vercel プロジェクト **forge** の env を確認 |

---

## 1. 投稿（作品を登録）

| | 内容 |
|---|---|
| **操作** | ログイン → 「作品を投稿する」→ 開発者プロフィール（初回）→ フォーム入力 → 投稿 |
| **成功** | 成功メッセージ。トップまたはダッシュボードに自分の作品が表示 |
| **失敗** | 「Supabase is not configured」等 → env / migration 001 未適用 |

**Dashboard 確認（任意）**: Table Editor → `projects` に新しい行

---

## 2. 更新を追う

| | 内容 |
|---|---|
| **操作** | 任意の作品詳細 → 「更新を追う」（ログイン済み） |
| **成功** | ボタンが「更新を追跡中」に変わる。リロード後も維持 |
| **失敗** | ログイン画面へ飛ぶ → 未ログイン。押しても変わらない → **002 未適用** の可能性 |

**アカウント A** で watch しておく（後の通知確認用）

---

## 3. 開発ログ投稿

| | 内容 |
|---|---|
| **操作** | **自分がオーナーの作品**の詳細 → 「開発ログを投稿」→ タイトル・内容 → 投稿 |
| **成功** | 詳細ページに戻る。「開発の歩み」に今投稿した内容が表示（サンプル表示ではない） |
| **失敗** | 赤エラー「開発ログの投稿に失敗しました… migration 003」→ **003 未適用**。リンクが出ない → その作品のオーナーではない |

**Dashboard 確認**: `project_devlogs` に 1 行増える

---

## 4. 開発ログ表示

| | 内容 |
|---|---|
| **操作** | 同じ作品の詳細を **別ブラウザ or シークレット**（未ログインでも可）で開く |
| **成功** | 「開発の歩み」に 3. で投稿したタイトル・内容が見える。「（サンプル表示）」が **出ない** |
| **失敗** | サンプル履歴のみ / 空 → DB に保存されていない（003 未適用 or 投稿失敗） |

---

## 5. 通知作成（watch → devlog）

| | 内容 |
|---|---|
| **操作** | **A** が作品を watch → **B**（オーナー）が devlog 投稿 |
| **成功** | Dashboard の `user_notifications` に A の `user_id` の行が 1 件以上（Table Editor で確認可） |
| **失敗** | 行がない → A が watch していない / B がオーナーでない / 003 未適用 / 002 の watch 未保存 |

※ アプリ上では **Realtime なし**。通知一覧は **ページを開いたとき** に反映。

---

## 6. 通知表示

| | 内容 |
|---|---|
| **操作** | **アカウント A** で `/notifications` を開く |
| **成功** | 「開発日誌」ラベル付きで「『作品名』に開発日誌が投稿されました」。クリックで作品詳細へ |
| **失敗** | 常に「通知はまだありません」→ 5. が失敗している。応援通知だけ見える → devlog 通知は DB、他は localStorage（仕様） |

## 失敗時の切り分け早見表

| 症状 | 第一候補 |
|---|---|
| 応援・watch・保存・FB が効かない | migration **002** 未適用 |
| devlog 投稿エラー | migration **003** 未適用 |
| watch したのに通知が来ない | A が watch 済みか / B がオーナーか / 003 適用済みか |
| ログイン自体ができない | Vercel **forge** の Supabase env |
| `forge-app-*.vercel.app` では動かない | 誤 URL。**forge-flame-gamma** を使う |
