## 8. 初声・みんなの声（migration 006 + 007）

**必須**: **006 と 007 は連続して適用**すること。006 のみ適用した状態では、問い archive 後に回答済み集計が公開 RPC から消える（007 で RPC を更新するため）。

1. `supabase/migrations/006_version_prompts_and_voice_responses.sql` を Run
2. 続けて `supabase/migrations/007_voice_prompt_immutable_aggregates.sql` を Run

006 だけ適用して止めない。007 は immutable 集計用の RPC 更新のみ（テーブル追加なし）。

**Table Editor 確認（任意）**:

- `project_version_prompts` がある
- `project_voice_responses` がある

### 8a. 開発者 — 問い設定（投稿 / 編集）

| | 内容 |
|---|---|
| **操作** | ログイン → `/submit` または `/projects/{id}/edit` → 「プレイヤーへの問い」で 1〜2 問を設定 → 保存 |
| **成功** | 保存後エラーなし。Dashboard の `project_version_prompts` に `source=developer` の行が増える |
| **失敗** | 保存エラー / テーブルなし → **006 未適用** |

未設定のまま投稿した作品では、プレイヤー側に **「もう一度遊びたい？」**（デフォルト問い）が表示される。

### 8b. プレイヤー — 初声（返事を届ける）

| | 内容 |
|---|---|
| **操作** | **別アカウント or シークレット**で作品詳細 → ログイン → プレイ → 「vX.X への返事」で **1 問だけ** 回答 → 「返事を届ける」 |
| **成功** | 「返事を届けました」表示。`project_voice_responses` に 1 行 |
| **失敗** | フォームが出ない / 送信失敗 → 006 未適用 or 未ログイン |

### 8c. みんなの声（集計のみ・個別非公開）

### 8f. immutable 問い履歴（007 適用後）

**前提**: v0.1 で問い 1 件設定 → 別ユーザー（A）が初声 1 件回答済み

**edit UI の注意**: 文言変更後に archive された旧問いは active 一覧に出ない。削除確認は **まだ active の問い** に対して行う。

#### 観点 1 — 回答済み active 問いを削除

| | 内容 |
|---|---|
| **操作** | 開発者（B）: `/projects/{id}/edit` → 回答済みの問いをリストから外す（削除）→ 保存 |
| **成功** | Dashboard: 該当 prompt に `archived_at`。みんなの声 / my-projects に**旧問い文の集計が残る**（007 適用必須） |
| **失敗** | 集計が消える → 007 未適用 or immutable save 未デプロイ |

#### 観点 2 — 回答済み問いの文言変更

| | 内容 |
|---|---|
| **操作** | B: edit で**同じ問いの文言だけ**変更 → 保存（削除ではない） |
| **成功** | Dashboard: 旧 prompt 行に `archived_at`、新 prompt 行が**別 id**。みんなの声に**旧文言の集計が残る** + 新問いは別 prompt（未回答ならグラフなし） |
| **失敗** | 旧文言の集計が新文言に置き換わる → immutable 未適用 |

**版跨ぎ（任意）**: devlog で v0.2 公開 → v0.2 用問い設定 → v0.1 / v0.2 の集計が `version_key` で分離されていること
