# migration 004 — オーナー本番確認（5分）

**URL**: https://forge-flame-gamma.vercel.app  
**作品**: 「消えるかな？」（自分がオーナーの作品）  
**所要**: 約 5 分（1 アカウントで OK。2 アカウントあると「新版 FB 枠」まで見やすい）

---

## 準備（30秒）

1. ブラウザで上記 URL を開く
2. 右上 **ログイン**（オーナーアカウント）
3. ヘッダー **ダッシュボード** をクリック → 自分の作品「消えるかな？」の **作品詳細** へ

---

## ① プレイ可能版 0.1 の表示（1分）

1. 作品詳細で **プレイ**（または外部リンク）を 1 回押す  
   ※ まだプレイ記録がなければ、これで FB フォームが出ます
2. ページを下へスクロール → **「プレイ後フィードバック」** を探す
3. **確認**：「プレイ可能版 **0.1**」という文字が見える

**OK の目安**：`0.1` と表示されている  
**NG**：フォームが出ない → もう一度プレイボタンを押してから再読み込み

---

## ② 同じ版で FB を編集（1分）

1. FB フォームに短文を入力（例：良かった点「テスト」）
2. **「フィードバックを送る」** を押す
3. **確認**：「フィードバックを**送信**しました」と出る
4. **「編集を続ける」** → 文字を変えて **「フィードバックを更新する」** を押す
5. **確認**：「フィードバックを**更新**しました」と出る

**OK の目安**：2 回目以降は「更新」扱い（件数が増えない）

---

## ③ 開発者：新版 devlog 公開（1分）

1. 同じ作品詳細 → **「開発ログを投稿」**
2. タイトル・内容を適当に入力
3. **「今回の更新を新しいプレイ可能版として公開する」** にチェック
4. バージョン名に **0.2** と入力（現在 0.1 と違う名前）
5. **投稿する**

**OK の目安**：詳細に戻る。エラーが出ない

---

## ④ 開発の歩み・ダッシュボード（1分）

1. 作品詳細の **「開発の歩み」** を見る  
   **確認**：今の devlog に **0.2**（または入力した版名）のラベル
2. ヘッダー **ダッシュボード** → **フィードバック** セクション  
   **確認**：「プレイ可能版 0.1」と「0.2」向け FB が **版ラベル付き** で見える（0.2 向け FB はまだ無くても OK）

---

## ⑤ 新版で新 FB 枠（1分・任意）

**別アカウント**（またはシークレットで別ユーザー登録）が理想：

1. 別ユーザーでログイン → 同作品を **プレイ**
2. FB フォームを開く  
   **確認**：「プレイ可能版 **0.2**」、フォームが **空**（0.1 用 FB は出てこない）
3. 新規送信 → ダッシュボード（開発者）で 0.2 向け FB が増える

1 アカウントだけの場合：③まで OK なら **新版 bump は成功** とみなしてよい。⑤は後日でも可。

---

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| FB フォームが出ない | プレイボタンを押したか / ログインしているか |
| devlog 投稿が赤エラー | Supabase Dashboard で 004 が Success か |
| 版が 0.1 のまま | チェックを入れたか / 0.1 と同じ名前を入れていないか |
| 更新にならない毎回新規 | 同じ版（0.1）向けか確認 |
