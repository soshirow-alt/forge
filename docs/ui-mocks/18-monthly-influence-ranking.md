## 右サイドバー

### 影響度ランキングとは

FB が作品・開発者に与えた**良い影響**を評価。

| アイコン | 基準 |
|----------|------|
| 💬 緑 | **役立つ声** — 開発者が「役立った」と評価 |
| 💗 桃 | **共感を集めた声** — 他プレイヤーから共感 |
| 🌱 紫 | **新人への貢献** — 新規開発者作品への FB |
| 🔄 青 | **継続して見届けた声** — 作品の成長を追った FB |

締め: **あなたの声が、ゲームの未来をつくる。**

→ 追加決定 §8–§10 と整合 ✓
