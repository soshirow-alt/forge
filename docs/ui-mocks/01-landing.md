## レイアウト概要

- **サイドバーなし** — 未ログイン LP。ヘッダー + ヒーロー + CTA 2 枚 + 注目作品 + お知らせ + フッター
- **テーマ**: ダーク。背景はファンタジーイラスト（ランtern・城・三日月）
- **アクセント**: 紫（プレイヤー）/ 緑（開発者）/ 青（登録ボタン）

### PC レイアウト方針（2026-06-15 確定）

- **NG**: 100dvh/fr で各セクションを個別伸縮、Hero/CTA/サムネだけ縦伸ばし、3価値を `justify-between` で散らす、**1080px 箱の内側余白を scale 対象に含める**
- **OK**: **1920 幅・実コンテンツ高さ**のアートボードにモック密度で px 配置 → **`scale = min(vw/1920, vh/実高)`** で全体等倍スケール
- **余白**: キャンバス内に空き箱を作らない。**viewport 外側**（主に下）に出す
- **実装**: `landing-page-scaler.tsx`（ResizeObserver で実高計測）+ `LandingPageCanvas`
- **モバイル（lg 未満）**: スケールなし・縦スクロール
