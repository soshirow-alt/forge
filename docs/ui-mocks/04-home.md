## メインコンテンツ

### A. ヒーローカルーセル — 注目の開発中ゲーム

| 要素 | 例 |
|------|-----|
| ビジュアル | 大横幅イメージ |
| タイトル | 星灯の旅路 |
| メタ | v0.4.0 • 昨日更新 |
| 説明 | 夜の森を旅する短編アドベンチャー… |
| 統計 | **声 24**（💬）/ **見届け人 15**（👤） |
| CTA | 詳しく見る → → **06** |
| UI | 左右矢印 + 下部ドット |

**ワッペン**: 開発中 — なし ✓

### B. 最近更新された作品

- 横 **5 カード** + **すべて見る →**
- カード: サムネ / タイトル / v0.x • N時間前更新 / 声・見届け人

### C. 今週人気の作品

- 横 **5 カード** + **すべて見る →**
- **ランキング番号バッジ** 1–5（左上）
- 人気指標 — 声・見届け人等（#12 発掘方針との関係）

### D. 新着作品

- 横 **5 カード** + **すべて見る →**
- 例: v0.1.0 • 1日前

### E. ジャンルから探す

- ピルボタン横並び: RPG / アクション / アドベンチャー / シミュレーション / パズル / ストラテジー / ホラー / その他
- → 05 検索 + ジャンル FF
