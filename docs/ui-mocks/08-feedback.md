## フォーム — 「質問に答える」

**本モックは 1 画面に集約** — 画面一覧の **第1段階+第2段階** が同一ページ（#31）

### Q1（必須）— チュートリアルの長さ

- 5 択ラジオ: 長すぎる ← → 短すぎる（**ちょうどよい** 選択例）
- 任意: 理由テキスト **0/500**

### Q2（必須）— バトル難易度バランス

- 5 択ラジオ（**ちょうどよい** 選択例）
- 任意: 理由 **0/500**

→ 選択式 + **任意自由記述（理由）** — 共感は自由記述 FB のみ（追加決定 §7）

### Q3（任意）— ストーリーについて

- テキストエリア **0/1000**

### Q4（任意）— その他の意見

- テキストエリア **0/1000**
